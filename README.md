# Интернет-магазин - базовые классы

## Описание проекта
Проект представляет собой ядро для интернет-магазина. Содержит базовые классы для работы с товарами и категориями.

## Функциональность

### Класс Product (Товар)
- Хранит название, описание, цену и количество товара
- Приватный атрибут `__price` с геттером и сеттером
- Сеттер проверяет, что цена больше нуля
- Класс-метод `new_product()` для создания товара из словаря

### Класс Category (Категория)
- Хранит название, описание и список товаров
- Приватный атрибут `__products`
- Атрибуты класса: `category_count` (количество категорий) и `product_count` (общее количество товаров)
- Метод `add_product()` для добавления товара
- Геттер `products` возвращает строку с товарами в формате: `"Название, X руб. Остаток: X шт."`
