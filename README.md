\# Интернет-магазин - базовые классы



\## Описание

Проект содержит базовые классы для интернет-магазина:

\- `Product` - класс для описания товара

\- `Category` - класс для описания категории товаров



\## Функциональность

\- Создание товаров с названием, описанием, ценой и количеством

\- Создание категорий с автоматическим подсчетом:

&#x20; - Общего количества категорий

&#x20; - Общего количества товаров во всех категориях
